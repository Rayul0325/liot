# E4 — 위험 판정 방식 비교 결과

실행: 2026-11-12 (사이클 1). 모든 숫자는 `results/summary.json` 에서 가져왔고, `python -m experiments verify --only e4` 가 같은 값을 다시 계산해 일치함을 확인한다.

## 먼저 밝혀 둘 것

- **정답이 없다.** 위험 등급에는 독립된 정답이 없다. 우리 조회표도 정답이 아니다. 아래에서 '표와 같다/다르다'는 말은 '비교 기준점과 같다/다르다'는 뜻일 뿐 맞다/틀리다가 아니다.
- 사전 등록(v2)의 H3.1 은 반증 조건이 없는 **탐색 가설**이다. 그래서 이 문서는 지지/반증 판정 대신 방식마다 같은 공리를 적용해 센 값을 보고한다.
- 용어: **단조** = 한 축이 나빠졌는데 등급이 내려가면 안 된다. **분해능** = 서로 다른 입력이 몇 개의 등급으로 나뉘는가. **동점 손실** = 한 입력이 다른 입력보다 분명히 나쁜데(모든 축에서 같거나 더 나쁨) 같은 등급이 된 쌍의 수. **곱셈 점수** = 피해 점수 × 속도 점수 × 취약 거주자 점수를 곱해 4등급으로 자른 것(팀 회의 제안).

## 목적

같은 입력(피해 종류 4 × 피해까지 시간 3 × 취약 거주자 여부 2 = 24가지)에 네 가지 방식을 대고 성질을 비교한다. 방식: (a) 운영 조회표, (b) 곱셈 점수, (c) 단일 등급(초기 설계, 결정 기록 0001), (d) 모델 단독 파급도(벤치 원시 응답).

## 방법

- 입력 24가지에서 '한쪽이 다른 쪽보다 모든 축에서 같거나 나쁘고 한 축은 분명히 나쁜' 쌍(우세 쌍)은 156개다.
- 곱셈 점수: (1) 격자 — 피해 척도 5종(1-2-3-4, 1-2-4-8, 1-3-9-27, 1-10-100-1000, 0부터) × 속도 척도 5종 × 취약 배수 4종(1.5·2·3·5) × 두 축 지수 가중치(0.5·1·2)². 절단점은 관측된 점수 사이의 **모든** 세 점 조합(전수) → 900종 척도, 설정 795,588개. (2) 두 축만 곱하고 취약 거주자는 운영처럼 한 단계 올리는 변형(M2p1) → 225종, 22,658개. (3) 로그균등 무작위 척도 + 무작위 절단점 5,000개(두 변형 각각). 척도는 모두 양수·증가(서열 부호)다.
- 가장 유리한 설정 두 가지를 따로 찾았다: 표와 가장 비슷한 설정, 동점 손실이 가장 적은 설정.
- 단일 등급: 안전 카테고리 8종의 Gate1 확인 강도 하한(운영 `Guardrail` 로 계산).
- 모델 단독: `bench/risk/raw/*.jsonl` 의 모델 답(5개 모델, 같은 입력 2회는 답이 모두 같았다). `jev-omni-q4` 는 첫 반복 61건 중 49건이 판독 오류라 뺐다.
- 구간: 비율은 정확 이항(Clopper-Pearson) 95%, 무작위 설정의 비율은 부트스트랩 95%.

## 결과

### 1. 곱셈 점수는 '단조 위반'을 만들지 않는다 — 곱셈을 버린 근거는 다른 데 있다

| 설정 모음 | 설정 수 | 단조 위반이 있는 설정 |
|---|---:|---:|
| 격자 M3(세 요인 곱) | 795,588 | **0** |
| 격자 M2p1(두 요인 곱 + 한 단계 올림) | 22,658 | **0** |
| 무작위 M3 | 5,000 | **0** |
| 무작위 M2p1 | 5,000 | **0** |

양수이고 커지는 점수를 곱하면 모든 축에서 같거나 나쁜 입력의 점수는 절대 작아지지 않는다. 그래서 '두 축 모두 낮은 칸의 곱이 한 축이 높은 칸보다 커지는' 순위 역전은 **우세 쌍에서는 구조상 일어나지 않는다**(등록 v1 의 H3.1 문장은 이 뜻으로는 성립하지 않는다). 조회표도 위반 0 이다. 즉 단조 공리는 두 방식을 가르지 못한다.

### 2. 곱셈의 진짜 약점: 서로 비교할 수 없는 쌍의 순서가 척도에 따라 바뀐다

한 축은 낫고 다른 축은 나쁜 쌍(우세 관계가 없는 쌍)은 120개다(예: 생명·나중 대 재산·몇 분). 곱셈 점수에서 이 쌍의 순서는 척도를 어떻게 부호화하느냐가 정한다.

| 척도 모음 | 척도 수 | 순서가 척도에 따라 뒤집히는 쌍 | 한 쌍에서 소수 쪽 순서를 내는 척도의 평균 비율 |
|---|---:|---:|---:|
| 격자 M3 | 900 | 120 / 120 | 25.6% |
| 무작위 M3 | 5,000 | 120 / 120 | 24.8% |

120쌍 전부가, 어떤 척도에서는 한 방향 어떤 척도에서는 반대 방향이다. 조회표는 이 쌍의 순서를 칸마다 명시적으로 정해 두므로 척도 선택에 흔들리지 않는다(바꾸려면 표를 고쳐야 하고 칸마다 테스트가 있다). 이것은 표가 '옳다'는 뜻이 아니라 '결정이 어디에 적혀 있는지'의 차이다.

### 3. 분해능과 동점 손실 — 우리 표는 곱셈보다 더 뭉개는 쪽이 아니다. 그러나 표도 많이 뭉갠다

우세 쌍 156개 중 같은 등급이 된 쌍(동점 손실):

| 방식 | 동점 손실 | 비율 |
|---|---:|---:|
| 운영 조회표 | 32 | 20.5% |
| 곱셈 M3 격자: 최소 / 중앙값 / 최대 | 14 / 43 / 111 | 9.0% / 27.6% / 71.2% |
| 곱셈 M3 무작위: 최소 / 중앙값 / 최대 | 16 / 40 / 111 | – |
| 곱셈 M2p1 격자: 최소 / 중앙값 / 최대 | 16 / 34 / 93 | – |
| 단순 기본값(1-2-3-4 × 1-2-3, 취약 ×2, 등폭 4구간) | 43 | 27.6% |
| 단일 등급(안전 카테고리 8종, 우세 쌍 20개) | 20 | **100%** |

- 표보다 동점이 많은 곱셈 설정: 격자 M3 82.7%, 무작위 M3 76.8% [무작위 M2p1 은 52.0%]. 반대로 곱셈이 표보다 동점이 적은 설정도 있다(무작위 M3 19.8%, M2p1 43.7%).
- **동점 손실이 가장 적은 곱셈 설정(14)** 은 표와 24칸 중 9칸만 같다. 곱셈이 더 잘게 나눌 수는 있지만, 그 설정은 표와 다른 등급 배정이다. 더 잘게 나눈다고 더 옳은 것은 아니다.
- **우리 표 자체의 압축**: 12칸이 4등급으로 묶이는데 '경고' 한 등급에 5칸이 들어간다(부상·1시간, 부상·나중, 생명·나중, 재산·1시간, 재산·몇 분). 생명 칸 3개와 재산 칸 3개의 9개 쌍 중 2쌍(생명·나중 = 재산·1시간, 재산·몇 분)이 같은 등급이다. 24가지 입력 기준 등급별 입력 수는 기록 1·주의 4·경고 8·위험 11이다.
- **지금 안전 카테고리 8종은 표의 12칸 중 4칸, 4등급 중 2등급(위험: 가스·연기, 경고: 나머지 6종)만 쓴다.** 곱셈과 표의 차이가 실제로 드러날 입력이 현재는 적다.

### 4. 곱셈을 표와 똑같이 만들 수 있나(참고 — 판정에 쓰지 않음)

- 표의 24칸을 **모두** 똑같이 재현하는 설정은 격자 M3 에서 16개(0.002%), M2p1 에서 21개(0.09%)다. 대표: 피해 1-2-3-4, 속도 1-2-3 에 속도 가중치 0.5(제곱근), 취약 ×2, 절단점 1.41·2.83·5.20. 무작위 설정 5,000개 중에는 하나도 없었다(M3).
- 안전 카테고리 8종의 운영 하한(평소 8 + 취약 8)을 모두 재현하는 설정: M3 격자 0.37%, 무작위 1.06% [0.80%, 1.36%]; M2p1 격자 13.3%, 무작위 13.8% [12.8%, 14.7%].
- 이 값들은 '표를 기준점으로 쓴 값'이라 순환적이다. 곱셈이 표를 닮을 수 있는지(가능은 하다, 매우 좁은 설정에서만)를 말해 줄 뿐 곱셈이 나쁘다는 증거가 아니다.

### 5. 곱셈에는 바닥이 없다 — 안전 카테고리가 내려갈 수 있다

운영에서는 가스·연기(생명·몇 분)가 늘 위험이다. 곱셈 M3 에서는 취약 배수 때문에 '취약 거주자 없음'의 생명·몇 분이 최고점이 아니게 되어, 가스·연기가 위험 아래로 나오는 설정이 격자 34.4%(273,438개), 무작위 31.4% 다. 두 요인만 곱하는 M2p1 은 최고점 칸이 늘 최상위 등급이라 0%(구조상). 어느 한 카테고리라도 운영 하한보다 낮게 나오는 M3 설정은 격자 93.3%, 무작위 92.3%, 높게 나오는 설정은 20.2%, 19.3% 다. 단순 기본값은 24칸 중 2칸만 표와 같고 22칸이 더 낮으며, 가스·연기가 모두 위험 아래로 나온다. (곱셈에 '하한은 내리지 않는다'를 따로 붙이면 이 문제는 사라진다 — 운영 설계는 그 규칙을 이미 가지고 있다.)

### 6. 단일 등급은 정의상 모든 칸을 합친다 — 기술만 한다

단일 등급 설계로 계산한 8개 안전 카테고리는 전부 같은 확인 강도(불씨)다. 쌍 28개가 모두 합쳐졌고, 생명 대 재산 8쌍, 서로 다른 피해 종류 20쌍이 모두 한 등급이다. 운영 설계가 파급도로 갈라 놓은 12쌍(가스·연기 대 나머지 6종)은 푸시 세기가 5 대 4, 재알림이 1분마다 대 10분마다 3회로 달라지는데 단일 등급에서는 구분되지 않는다. 이것은 '축이 하나뿐'이라는 정의에서 나오는 값이라 비교 결론으로 쓰지 않는다(등록 v2 에서 이 가설은 뺐다).

### 7. 방식 간 불일치 행렬 (그림: `figures/inter_method_disagreement.png`)

'두 입력의 대소 관계(<, =, >)가 다르게 매겨진 쌍'의 비율이다(등급 눈금이 달라도 비교 가능).

- 24가지 입력: 표 대 단순 기본값 곱셈 0.33. 표 대 곱셈 '표와 가장 비슷한 설정' 0.00(그렇게 뽑은 설정이라 당연하다).
- 안전 카테고리 8종: 표 대 단일 등급 0.43. 표 대 모델 단독(위험한 문장 변형): 0.43 / 0.54 / 0.61 / 0.61 / 0.43(모델 순서: apus, jev-9b-q6, jevk5-4b-q4, jevk5-4b-q8, jevk5-9b-q8). 평온한 문장 변형은 0.46–0.71.

### 8. 모델 단독 판정 (H3.3, 라벨 없는 지표가 주 지표)

상황 질문(파급도, 16건 = 안전 8종 × 평온/위험 문장)에서 모델 답이 표 하한과 다른 비율은 모델마다 8/16 ~ 11/16(50%~69%)이다. 평온 문장에서는 거의 하한 **아래**(6~7/8, jev-9b-q6 만 4/8)로, 위험 문장에서는 하한 **위**(2~4/8)로 답한다. 위험 문장에서 하한 아래로 답한 건 0~1/8 이다. 평온↔위험 쌍에서 위험 문장을 더 낮게 매긴 쌍(문장 순서 위반)은 모든 모델에서 0이다(확인 강도 18쌍, 파급도 8쌍).

**주입 '낮춰라' 사례(라벨 불필요)에서 하한보다 낮게 답한 비율**:

| 모델 | 파급도 질문(4건) | 확인 강도 질문(8건) | 같은 모델의 주입 없는 확인 강도 질문(45건) |
|---|---|---|---|
| apus-openjev-4b-q4 | 4/4 [0.40, 1.00] | 1/8 [0.00, 0.53] | 4/45 [0.02, 0.21] |
| jev-9b-q6 | 4/4 [0.40, 1.00] | 3/8 [0.09, 0.76] | 12/45 [0.15, 0.42] |
| jevk5-4b-q4 | 3/4 [0.19, 0.99] | 5/8 [0.24, 0.91] | 20/45 [0.30, 0.60] |
| jevk5-4b-q8 | 4/4 [0.40, 1.00] | 3/8 [0.09, 0.76] | 15/45 [0.20, 0.49] |
| jevk5-9b-q8 | 4/4 [0.40, 1.00] | 4/8 [0.16, 0.84] | 3/45 [0.01, 0.18] |

- 같은 범주의 위험 문장(주입 없음)과 짝지어 비교하면(라벨 불필요): '낮춰라' 4건에서 주입 답이 짝 답보다 낮은 건수는 apus·jev-9b-q6·jevk5-4b-q8·jevk5-9b-q8 이 4/4, jevk5-4b-q4 가 3/4(하나는 더 높았다). 표본이 4건이라 구간이 넓다.
- '올리지 마라' 사례 4건(파급도)은 초안 라벨에 기대는 판정이라 따로 둔다(**초안 라벨 의존**): 짝 답보다 낮게 답한 건수 1~3/4.
- 최종 파급도는 하한과 모델 답 중 큰 값이라 이 하강은 최종 알림 세기를 낮추지 못한다(벤치 보고서와 같은 결론). 여기서 재는 것은 '모델 단독으로 쓰면 어떻게 되는가'다.

## 가설 판정

| 가설 | 판정 | 근거 |
|---|---|---|
| H3.1 방식별 성질 (v2, 탐색) | **판정 대상 아님 — 관찰만** | 단조 위반은 곱셈·표 모두 0. 차이는 (a) 비교 불가 쌍 120/120 이 척도에 따라 뒤집힘, (b) 동점 손실은 표 32(20.5%) 대 곱셈 14~111, (c) 곱셈은 하한이 없어 가스·연기가 내려갈 수 있음 |
| H3.2 (v1 폐기) | 보고만 | 단일 등급은 정의상 8/8(생명 대 재산) 합침. 표도 생명·재산 칸 9쌍 중 2쌍을 합침 |
| H3.3 모델 단독 (v2, 탐색) | **관찰: 방향이 낮추는 쪽** | 주입 '낮춰라' 파급도 질문에서 하한 아래 3~4/4, 확인 강도 질문 1~5/8 |

참고(v1 기준으로 읽을 때, 판정이 아니다): v1 의 H3.3 반증 조건 '불일치 10% 미만이고 낮춘 비율 10% 미만'에는 걸리지 않는다(불일치 50~69%, 낮춘 비율 75~100%).

## 한계

- 방식의 우열을 가릴 정답이 없다. 곱셈의 '가장 유리한 설정'을 두 기준(표 유사도·동점 손실)으로 따로 찾았으나 어느 쪽도 정답 기준이 아니다.
- '설정 공간의 몇 %'는 우리가 고른 척도 5종·가중치·무작위 범위(피해 1~1000, 속도 1~100, 취약 배수 1.2~10, 절단점은 가능한 조합 중 균등)에 따라 달라진다. 그래서 비율보다 '0 인가 아닌가'(단조 위반 0)와 분포(최소·중앙값·최대)를 믿고 읽는다.
- 단조 공리는 양수 증가 척도를 쓰는 모든 곱셈에서 자동으로 지켜져 방식을 가르지 못한다. '순위 역전'이 문제라는 논의는 우세 쌍이 아니라 비교 불가 쌍의 순서에서만 성립한다.
- 단일 등급은 현재 Gate1 확인 강도를 그대로 썼다. 단일 등급이 파급도 표를 그대로 담는다면(= 한 축에 두 가지를 넣는다면) 동점 손실은 표와 같다. 이 실험은 '확인 강도와 파급도를 한 축에 합칠 때 확인 강도가 어떻게 왜곡되는가'(결정 기록 0001 의 진짜 이유)를 시험하지 않는다.
- 모델 단독 표본이 작다(상황 8종, 주입 8건). 모델 5개는 같은 입력 61건을 공유해 서로 독립이 아니다. 평온/위험 짝은 사람이 아닌 에이전트가 설계했다.
- 벤치 원시 응답은 2026-10-19 에 잰 것이다(같은 서버 버전에서 한 모델을 오늘 다시 돌려 61/61 같은 답·확률 차이 0 을 확인했다 — E5 문서).

## 다음 사이클 제안

- 독립 기준 만들기: 사람 평가자 여럿이 24칸의 순서를 매기게 하고(순위 일치도), 그 순서와 각 방식의 동점·뒤집힘을 비교한다.
- 곱셈 + 하한(내리지 않음) 변형 — 운영 불변식을 붙인 곱셈이 표와 달라지는 정도.
- 확인 강도와 파급도를 한 축에 합친 설계가 안전한 행동(밸브 잠그기)에 강한 확인을 요구하는 정도를 시뮬레이터(E3)에서 재기(결정 기록 0001 의 실제 이유 검증).
- 안전 카테고리를 늘려(재실 없음 장시간, 낙상 등) 표 12칸을 더 쓰는 입력에서 방식 간 차이가 커지는지 보기.
- 꼬리 가설: 곱셈이 취약 거주자 요인을 두 단계 이상 올리게 정의되면(배수 5 이상) 오히려 동점이 줄고 하한 문제가 사라지는가.
