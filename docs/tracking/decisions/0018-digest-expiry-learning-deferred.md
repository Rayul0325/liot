# 0018. 모아보기 만료를 비선호 학습에서 빼는 고침은 단독으로 적용하지 않는다

- 날짜: 2026-11-12
- 상태: 채택

## 맥락

`findings.md` 의 '모아보기(DIGEST)가 실제로는 전달되지 않아…' 항목은 접근 하나로 '모아보기 항목의 만료를 비선호 신호로 세지 않는다'를 든다. 모아보기를 내보내는 경로가 없어, AMBIENT 제안은 아무도 보지 못한 채 만료되고 `_apply_expired_signals` 가 이를 약한 비선호로 학습한다.

## 결정 (2026-11-12, 소유자 위임: 추천안)

그 고침을 **단독으로 적용하지 않는다.** 근거: E13 C4.7 (1), `experiments/e13_adapt_rules/RESULTS.md`. 모아보기를 아무도 열지 않는 실제 데몬(tray0)에서 만료 학습을 빼면 폰 장면의 수락된 도움이 운영 대비 −0.070 [−0.150, −0.011] 로 낮아진다. 모아보기 장면이 '한 순간에 제안 하나' 선택에서 더 자주 이기고, 폰 장면의 비선호는 계속 배우기 때문이다(RESULTS 가 밝힌 기제이며 상호작용만 떼어 시험한 팔은 없다). 이 고침은 모아보기를 실제로 전달하는 경로(또는 다른 보완)와 함께 다룬다.

## 대안

- 단독 적용: 위 근거로 기각. tray0 에서 폰 도움이 줄어든다.

## 결과

- 코드 변경 없음. `findings.md` 항목에 이 결정과 근거를 덧붙였다.
- 결정 0016 의 보류 제안은 선호 셀 추적에 넣지 않아 이 문제를 새로 만들지 않는다.
