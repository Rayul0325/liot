# 0011. 119 는 안내만 하고 자동 신고하지 않는다

- 날짜: 2026-10-19
- 상태: 채택

## 맥락

위험 상황에서 거주자도 보호자도 응답하지 않으면 다음 단계가 필요하다. 자동 신고는 가장 강한 대응이지만, 센서 오작동(HA 재시작 시 상태값 이상 등)·오판 때 출동 비용과 책임이 생긴다.

## 결정

보호자 전달 5분 뒤(보호자가 없으면 상황이 열리고 90초 + 5분 뒤)에도 아무도 확인하지 않으면, 거주자와 전달받은 보호자에게 "119에 직접 전화해 주세요(자동 신고 아님)" 문구와 상황 요약을 보낸다. 어떤 코드 경로도 전화를 걸거나 신고 API 를 부르지 않는다. 이 경로도 파급도 하한이 위험일 때만이다.

## 대안

- 자동 신고: 오작동 시 책임 소재가 불분명하고, 센서의 fail-closed(못 읽으면 이상) 설계와 겹치면 거짓 신고가 난다. 보류.
- 119 단계 없음: 아무도 응답하지 않는 위험 상황에서 마지막 행동 지침이 없다. 기각.

## 결과

- 실제 신고 여부는 사람에게 남는다. 아무도 알림을 보지 않으면 신고되지 않는다.
- 119 안내는 상황당 한 번이다(송신이 모두 실패하면 재시도한다).
- 자동 신고를 넣으려면 이 결정을 다시 열어야 한다.
