- 필수 조건(두 질문 합계 p95 < 1.0초)을 통과한 모델은 없다. 가장 가까운 것은 jevk5-4b-q8(p95 1.025초). 측정 때 기계 부하가 높았다(load average ≈ 10, 같은 모델 안에서 처리량이 두 갈래로 갈림). 재측정이 필요하다.
- 하한 합성 덕분에 최종값이 하한 아래로 내려간 경우는 없다. 모델 자체는 '낮춰라' 문장을 자주 따랐다.
- 기본 모델은 정하지 않았다. `LIOT_DECISION_MODEL` 기본 이름(`jevk5-9b`)은 기록용 이름일 뿐 선정 결과가 아니다.

## 막힌 것

- 기본 결정 모델 선정은 시험 세트 라벨의 소유자 검토(draft → confirmed)가 먼저다. 라벨이 확정되기 전에는 기본값을 바꾸지 않는다.

## 남은 것(먼저 할 순서)

1. 시험 세트 라벨 소유자 검토·확정.
2. 조용한 기계에서 후보 재측정 → 선정 기준(2회 동일 + p95 < 1초 → 과잉 올림 ≤ 10% 중 올림 비율 최고)으로 기본 모델 확정. 소형 허브(4B 이하) 최선 모델도 따로 표시.
3. 데몬 전체를 실제 llama.cpp 서버·실제 HA·실제 ntfy 에 붙여 한 번 끝까지 돌려 보기(가스 이상 → 즉시 알림 → 2단계 판단 행 → 사다리 → 정상 복귀).
