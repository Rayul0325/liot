이제 손이 필요하다

조작(actuation)을 켜면 LIOT은 더 이상 알려주기만 하지 않습니다 — 직접 끄고, 닫고, 잠급니다. 그래서 이번에 살 것은 "읽는 센서"가 아니라 "움직이는 액추에이터"입니다. 단, 모든 손에는 규칙이 있습니다. 무엇을 사든 그 손이 어떻게 게이트되는지부터 봅니다.

00 사기 전에 — 손의 규칙

아래 표의 모든 제품에는 이 네 배지 중 하나가 붙습니다. 같은 기기라도 그 순간의 위험도(티어)에 따라 자동에서 확인으로 승격합니다. 옵트인이 꺼져 있으면(LIOT_EXECUTION_ENABLED 미설정) 전부 "알림만"으로 떨어집니다.

자동

비안전 + 저위험. 빈방 조명 끄기처럼 가역적인 것은 알림과 함께 즉시 실행.

AUTO · tier ≤ BREATH
단일확인

비안전이지만 영향이 큰 동작. 폰에서 한 번 탭하면 실행.

CONFIRM · DUSK
이중확인

비안전 최고위험, 그리고 모든 안전장치. 두 번 눌러야 실행 — 자동은 절대 없음.

DOUBLE · EMBER / 안전
알림만

화이트리스트 밖이거나 "여는 방향"이거나 비활성. 조작하지 않고 알리기만.

NOTIFY_ONLY
fail-safe 방향만
✓ 밸브 닫기 · 문 잠그기 ✗ 밸브 열기 · 문 열기/해제

안전 액추에이터는 "안전해지는 방향"으로만 움직입니다. 여는 동작(lock.unlock, valve.open)은 화이트리스트에서 코드로 제외됨 — AI가 당신의 집을 여는 일은 없습니다.

02 안전 액추에이터 — fail-safe 방향만

SAFETY_EXECUTABLE는 단 둘뿐입니다: valve.close, lock.lock. 절대 자동 안 됨 — 이중확인을 거쳐야만, 그것도 잠그는 방향으로만 움직입니다. 살 때 KC 인증과 HA 연동을 반드시 재확인하세요.

여는 손은 사지 않아도 됩니다: 코드가 unlock·valve.open을 화이트리스트에서 제외하므로, 도어락을 사도 LIOT은 잠그기만 합니다. 해제는 항상 당신 손으로 — 침입·오판·인젝션이 문을 여는 경로가 구조적으로 없습니다.

05 사고 나서 — 조작 켜기

기기를 HA에 페어링하고, 옵트인 플래그를 켜면 됩니다. 안 켜면(기본) LIOT은 지금처럼 제안만 합니다.

# HA 연결 + 조작 활성 (셋 다 필요) LIOT_HA_URL=ws://homeassistant.local:8123/api/websocket LIOT_HA_TOKEN=<장기 액세스 토큰> LIOT_EXECUTION_ENABLED=true # 이게 없으면 제안-만 유지 # 데몬 기동 시 한 줄로 확인: # [LIOT] ... exec=ON ... ← 손이 켜짐 # [LIOT] ... exec=off(제안-만) ... ← 아직 알림자

로컬 제어 우선: 클라우드 전용 기기(앱 없으면 안 되는 WiFi 제품)는 피하세요. Zigbee·Matter·Z-Wave 또는 로컬 API 기기를 골라야 인터넷이 끊겨도 LIOT이 손을 쓸 수 있고, 외부 서버에 집 상태가 새지 않습니다.

되돌리기는 기기가 상태를 보고할 때 의미 있음: LIOT은 조작 직전 상태를 캡처해 "되돌리기"를 제공합니다. 밝기·온도·위치 값을 HA로 보고하는 기기여야 정확히 복원됩니다(대부분의 Zigbee 기기는 보고함).
